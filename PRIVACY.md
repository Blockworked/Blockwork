# Privacy Policy

Last updated: 2026-10-20

Blockwork is an open-source desktop app for building and running keyboard and
mouse macros. It runs entirely on your device.

## What Blockwork collects

The Blockwork app does not collect, store on our servers, or transmit any personal
information, keystrokes, mouse activity, or usage data. It has no accounts,
analytics, telemetry, or advertising. The optional community block library
website is covered below.

## Input recording

Blockwork listens to keyboard and mouse input system-wide so it can record
macros and trigger them with hotkeys. Recorded input is only turned into a
macro when you start a recording. Macros, variables, and settings are saved as
local files on your device and are never sent anywhere. You can delete them at
any time by removing the app's configuration folder.

## Network access

Blockwork makes no network connections for its own purposes. The only
exception is the optional update check in the GitHub download, which contacts
GitHub's public releases API to see whether a newer version exists. This check
is disabled in the Microsoft Store version, where updates are delivered by the
Store. The block library under My Blocks > Browse library downloads its list
of packs, and any pack you add, from community.blockworked.com and from any
other library address you add in Settings. Blockwork also runs a local-only control connection on your own machine
(loopback) so other programs you run can trigger macros. It is not reachable
from other devices.

## Community block library

The community block library at https://community.blockworked.com is a
separate website. Browsing it and adding packs from it needs no account.
To submit a pack you sign in with GitHub or Google; the site keeps your
account id, display name and profile picture address from that provider,
the packs you upload, and a sign-in session cookie. Packs you submit are
reviewed, and once listed they're public along with your display name.
Neither the website nor the app sends your macros, recordings or input
anywhere unless you upload a pack yourself. To have your account or packs
removed, open an issue at the address below.

## Third parties

Blockwork does not share data with third parties. The app interface is built
with Qt 6/QML, which runs locally.

## Changes

If this policy changes, the new version will be published in this repository
with an updated date.
